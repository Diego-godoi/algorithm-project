# algorithm-project

Projeto em C.

## Estrutura

- `app/` — arquivos fonte (`.c`) e cabeçalhos (`.h`)
- `app/main.c` — ponto de entrada

## Compilar e rodar

```sh
make       # compila tudo em app/ -> executável algorithm-project
make run   # compila e executa ./algorithm-project
make clean # remove o executável
```
